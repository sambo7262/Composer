## Vibe.is_active Filter (Blocker #7)

Both vibe pool helpers carry the symmetric `is_active = 1` clause:

- `_read_vibe_pool_weights_sync` — `WHERE v.is_active = 1` in the GROUP BY (archived vibes contribute zero weight)
- `_read_top_n_for_vibe_sync` — `JOIN vibe v ON v.id = tv.vibe_id ... AND v.is_active = 1` in the WHERE (archived vibes return empty pool)

Three regression tests confirm the invariant end-to-end:

- `test_refill_mirror_sql_excludes_archived_vibes_from_pool_weights`
- `test_refill_mirror_sql_excludes_archived_vibe_members`
- `test_create_then_archive_vibe_excludes_subsequent_picks`
