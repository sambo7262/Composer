### Module Placement note (planner's call)

CONTEXT.md "Claude's Discretion" leaves the new-module decision open:
> "A new module file (planner picks name) holding `discovery_call_weekly` (the LLM cron job), `compute_discovery_eligible()`, `compute_adaptive_pick_count()`, `refill_mirror_sql()` — likely `app/services/suggestions_discovery.py` or fold into `app/services/suggestions_service.py`"

**Pattern signal from the codebase:**
- `vibe_service.py` (slot logic) and `vibe_clusterer.py` (clustering math) are split across two service modules even though both touch the same Vibe table — split-on-concern is the established convention.
- `suggestions_service.py` is already 1767 lines; adding a weekly LLM call + adaptive pick math + the SQL refill query template will push it past 2200.
- BUT — keeping `refill_mirror_sql()` next to its existing `_write_refill_results_sync` callsite simplifies the diff.

**Recommendation for planner:** SPLIT.
- `app/services/suggestions_service.py` keeps `refill_mirror_sql()` (the new SQL hot path) so the existing `_write_refill_results_sync` + `_next_mirror_position_sync` helpers stay co-located. DELETE `refill_suggestions_queue` + the entire LLM section in this file.
- NEW `app/services/suggestions_discovery.py` owns `discovery_call_weekly()`, `compute_discovery_eligible()`, `compute_adaptive_pick_count()`, the discovery prompt builders, and the `plays_since_last_discovery` counter accessor. Mirrors the `vibe_service` / `vibe_clusterer` split-on-concern pattern.

**Cross-vibe weighted pool** (D-B1):
```python
def _read_vibe_pool_weights_sync() -> List[Tuple[int, float]]:
    """Return [(vibe_id, library_share), ...] — proportional to rated track count per vibe."""
    with Session(get_engine()) as session:
        rows = session.execute(text(
            """
            SELECT v.id, COUNT(tv.track_id) AS member_count
            FROM vibe v
            LEFT JOIN trackvibe tv ON tv.vibe_id = v.id
            WHERE v.is_active = 1
            GROUP BY v.id
            """
        )).all()
        total = sum(r[1] for r in rows) or 1
        return [(r[0], r[1] / total) for r in rows]
```
**Apply:** Library-share-proportional allocation across vibes. If 40% of TrackVibe rows live in vibe X, ~12 of 30 picks come from X.

**Top-N + light randomization** (D-B2):
```python
TOP_N_PER_VIBE = 100  # planner can refine post-deploy

def _read_top_n_for_vibe_sync(vibe_id: int, n: int = TOP_N_PER_VIBE) -> List[dict]:
    """Return top N closest-to-centroid TrackVibe rows for the given vibe,
    ORDERED BY distance ASC, JOINED with track metadata. Caller picks from
    this pool with random.sample to add variety without destroying taste-fit.
    """
    with Session(get_engine()) as session:
        rows = session.execute(text(
            """
            SELECT t.id AS track_id, t.plex_rating_key, t.title, t.artist,
                   tv.distance, tv.vibe_id
            FROM trackvibe tv
            JOIN track t ON t.id = tv.track_id
            WHERE tv.vibe_id = :vid
              AND t.id NOT IN (SELECT track_id FROM suggestionsmirror)
            ORDER BY tv.distance ASC
            LIMIT :n
            """
        ), {"vid": vibe_id, "n": n}).all()
        return [dict(r._mapping) for r in rows]
```

def schedule_discovery_call_weekly() -> None:
    """Phase 7.1 — register the weekly LLM discovery call.

    Fires Sunday 03:00 UTC per D-C1 — off-peak for US timezones,
    aligned with existing infrastructure (matches sync_service /
    soft-negative-sweep cadence).

    # suggestions_discovery (which imports from suggestions_service which

        discovery_call_weekly,
        trigger=CronTrigger(day_of_week="sun", hour=3, minute=0, timezone="UTC"),
        id="discovery_call_weekly",

```python
def _read_discovery_state_sync() -> DiscoveryState:
    """Read or initialize the singleton DiscoveryState row."""
    with Session(get_engine()) as session:
        row = session.exec(select(DiscoveryState).where(DiscoveryState.id == 1)).first()
        if row is None:
            row = DiscoveryState(id=1)
            session.add(row)
            session.commit()
            session.refresh(row)
        session.expunge(row)
        return row


def _increment_plays_since_discovery_sync() -> int:
    with Session(get_engine()) as session:
        row = session.exec(select(DiscoveryState).where(DiscoveryState.id == 1)).first()
        if row is None:
            row = DiscoveryState(id=1, plays_since_last_discovery=1)
        else:
            row.plays_since_last_discovery = (row.plays_since_last_discovery or 0) + 1
        session.add(row)
        session.commit()
        return row.plays_since_last_discovery
```
