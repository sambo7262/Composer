    - Read SetupState.draft_proposals_json + the current Vibe table (existing vibe rows BEFORE this commit)
    - Snapshot manual overrides: SELECT all TrackVibe rows where assigned_by='manual', join Vibe to get the source vibe name (D-22)
    - For each VibeProposal in draft set, dispatch on action:
      a. action="keep" or "renamed_from": find existing Vibe by source_vibe_ids[0] → UPDATE name, description, centroid, spread, silhouette, centroid_recomputed_at=now; if name changed, plex_playlist_service.rename_playlist(plex_rating_key, "Composer · " + new_name); reconcile members additively via update_playlist_items
      b. action="dropped": find existing Vibe by source_vibe_ids[0] → plex_playlist_service.archive_playlist(plex_rating_key, current_composer_name); SET Vibe.is_active=False; ManagedPlaylist row already DELETED inside archive_playlist (D-21 invariant)
      c. action="merged_from": archive each source_vibe (per b), then INSERT new Vibe + create_playlist with union of members (D-21 — two drops + one new)
      d. action="split_from": archive the source vibe (per b), then for each split target INSERT new Vibe + create_playlist (D-21 — one drop + N news)
      e. action="new": INSERT Vibe + create_playlist with seed_track members + initial slot-in pass via vibe_service.slot_track for the rest of the rated set (D-25 sequential under semaphore=1)
    - Each operation wrapped in try/except → log + continue (D-23 idempotency on partial failure); collect failures for the response banner
    - After commit: replay manual overrides per D-22 — for each snapshot row, find the new vibe by name match (or via VibeProposal.source_vibe_ids → kept-from-which-old-vibe) and INSERT TrackVibe(assigned_by='manual'); if old vibe was dropped with no successor, log to SlotInLog as "manual override lost"
    - Run reconciliation pass: re-fetch every Composer · playlist from Plex; compare with ManagedPlaylist registry + Vibe.is_active state; surface drift on /debug/vibes (drift_indicator partial reads from this state)
    - SetupState.recluster_mode=False; SetupState.step="done"
