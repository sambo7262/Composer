api_setup.py routes (D-06, D-08, D-25):
  POST /api/setup/step1/submit  — Read rated count; if >=30 (or 30-49 degraded path) update SetupState.step=webhook; HX-Redirect to /setup/webhook (or /setup/propose if webhook already configured per D-06).
  GET  /api/setup/rated-count   — Returns rated-count partial (HTMX swap for the cold-start Refresh count button).
  POST /api/setup/step2/submit  — No-op other than advancing SetupState.step=proposing; HX-Redirect /setup/propose.
  POST /api/setup/propose/init  — Called on Step 3 first load if SetupState.draft_proposals_json is empty; calls vibe_clusterer.initial_cluster_proposal(forced_k); persists to SetupState.draft_proposals_json; persists last_llm_call_id (read latest LLMUsage row id with purpose=vibe_clustering_initial); returns the proposal-cards partial.
  POST /api/setup/refine        — Form field message: Annotated[str, Form()]. Reads SetupState.draft_proposals_json, deserializes via VibeProposalSet.model_validate_json, calls vibe_clusterer.refine_proposals(prior, message, recluster_mode=False), persists new draft_proposals_json + increments refinement_turn_count + updates last_llm_call_id. Returns the refreshed proposal-cards partial (HTMX morph swap target #proposal-cards).
  POST /api/setup/finalize      — Reads SetupState.draft_proposals_json. For each VibeProposal with action != "dropped":
    1. INSERT Vibe(name, description, centroid_*, spread_*, silhouette_score, created_at=now, is_active=True)
    2. Pre-compute initial member set from proposal's seed_track_indices + materialize_clusters output (vibe_clusterer already populated this in proposal.centroid + .spread + .silhouette).
    3. await plex_playlist_service.create_playlist(plex_url, plex_token, "Composer · " + name, [member rating keys])  — runs sequentially under asyncio.Semaphore(1) per D-25.
    4. After playlist creation, INSERT TrackVibe rows for each member (assigned_by=cluster), distance computed in z-score-normalized space.
    5. Update ManagedPlaylist row vibe_id (linked to the new Vibe.id).
    Returns push_to_plex_banner.html partial (state machine: running / completed / failed).
  POST /api/setup/reset         — Sets SetupState.step=rating_source + clears draft_proposals_json + zeroes refinement_turn_count. Used by Plan 04 settings page Run setup wizard again link. Returns 204 with HX-Redirect /setup.

SetupState row contract (D-08; Plan 01 ships the schema):
  id=1 (single-row pattern)
  step: rating_source | webhook | proposing | confirming | done
  draft_proposals_json: str — full VibeProposalSet JSON dump
  refinement_turn_count: int — 0 on init, incremented per refine call, cap at 10 (D-04)
  last_llm_call_id: Optional[int] — soft FK to LLMUsage.id of the most recent vibe_clustering_* call
  started_at, completed_at: ISO 8601 UTC
